# The Dog Bond

A premium Next.js/Tailwind authority website about the human–dog bond: companionship, training, protection, behaviour, breed character, responsible ownership, and African dog life.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploy

Push this folder to GitHub and import the repository into Vercel. Vercel will detect Next.js automatically.
